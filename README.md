# LegalEase: AI-Powered Legal Document Generator

LegalEase is an educational AI-powered project designed to help users generate structured draft legal documents from the information they provide.

## Project Overview

LegalEase aims to simplify the preparation of common legal document drafts by using a user-friendly interface and AI-assisted text generation.

## Main Features

- Select a document type
- Enter required information
- Generate a structured draft
- Review and edit the generated content
- Preview the document
- Download the final document
- Simple and user-friendly interface

## Project Technologies

- Python
- Streamlit
- Google Gemini API
- HTML/CSS where applicable

## Educational Purpose

LegalEase is developed as a student project for educational purposes. The generated documents are drafts and should be carefully reviewed. LegalEase does not replace advice from a qualified legal professional.
